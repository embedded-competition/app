# 커밋·푸시 규칙

파일을 고친 뒤 곧바로 `git commit`/`git push`를 하지 않는다. 사용자가 변경 내용을 먼저 검토할 시간을 주고, 사용자가 "커밋해"/"커밋하고 푸시해" 등으로 명시적으로 지시할 때만 커밋·푸시한다. 코드든 문서(CLAUDE.md, api-spec.md, docs/ 등)든 예외 없음.
